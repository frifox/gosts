Setup

The two top servos move together as one group, the leader deciding the goal. Mark the servo that faces its partner as mirrored, so the same command tilts both the same way. Elevation 0° is the camera level with the object (the servos' own 0°, set with gosts-ctl → Set 0° to), positive is up; invert if it goes the wrong way. Azimuth 0° is the platform's own 0°.

The rig's servos are always switched to multi-turn mode when gosts-rig connects, so every move can take the short way: in single-turn mode a move across a servo's 0/360° point goes the long way, nearly a full turn, which could swing the frame into the posts.
